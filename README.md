# Camera Calibration and Augmented Reality

Course project by Sriram Pandi and Srinivas Peri. The examples cover camera calibration, Harris corners, and projecting images onto ArUco markers.

- [Project report](CS5330%20Project-4%20Report.pdf)
- [Calibration](pr4_prt-1.cpp.txt), [Harris](harris.cpp.txt), and [AR](ARmain.cpp.txt) source listings
- [Original Visual Studio and OpenCV setup notes](Read_Me_prcv.txt)

The C++ examples are stored as text. For a local build, add the desired listing as a C++ source file to a Visual Studio project with OpenCV configured. The original setup notes reference a separate Visual Studio project archive.
